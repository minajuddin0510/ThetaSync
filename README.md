# ThetaSync 📉

A modern ROI and capital analysis calculator built for traders, investors, and finance enthusiasts.

ThetaSync helps calculate the actual return percentage by deriving the original capital from the final balance and profit amount.

Built with a clean fintech-inspired UI using pure HTML, CSS, and JavaScript.

---

## ✨ Features

- Real-time ROI calculation
- Automatic original capital calculation
- Decimal number support
- Beautiful glassmorphism UI
- Dark fintech dashboard aesthetic
- Responsive design for desktop and mobile
- Copy result functionality
- Reset button
- Number formatting with commas
- Smooth animations and transitions
- Beginner-friendly code structure
